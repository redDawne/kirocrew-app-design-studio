How it works

  1. 1

    Wrap the test step

    tapedeck record -- pytest -n 8 in any CI: GitHub Actions, Buildkite, CircleCI, Jenkins.

  2. 2

    Failures upload, passes vanish

    Only red and retried runs are kept, encrypted with your key.

  3. 3

    Replay with your debugger

    Clock, randomness, threads and network replay exactly. Attach Delve, pdb, lldb or VS Code and step through the failing run as many times as you want.
